# 方案 B：伴侣 + 工作台双层 (Companion + Workbench) 详细设计规范与状态映射

## 1. 命题与核心哲学
默认歌词伴侣与完整歌曲工作台形成明确但连贯的双层结构。默认是极具亲和力的歌词伴侣；右上角拥有明确的“歌曲工作台”常驻按键，点击后从右侧滑出 380px 的专业 Inspector 工作台，将歌词来源、翻译、读音、排轴与版本历史一站式收纳。

## 3. 优势与风险评估
- **优势**：伴侣与工作台的“双层”界限极度清晰，既不会打扰普通听歌，又为高级 DIY 用户提供了无缝的深度接管环境。
- **风险**：工作台展开时占用 380px 宽，在 800px 较小窗口下可能导致歌词区显得紧凑（需要响应式收缩）。
