# 方案 C：语境融合 (Contextual Fusion) 详细设计规范与状态映射

## 1. 命题与核心哲学
不设置明显的“进入工作台”模式，而是让操作随当前歌词、当前状态和用户动作逐层出现。点击歌词行弹出行级微型控制，点击歌曲标题弹出曲目元数据 Popover，点击状态点弹出连接与 Provider 诊断。

## 3. 优势与风险评估
- **优势**：没有强烈的“切换到工作台模式”的割裂感，操作在看歌词、听歌时自然发生。
- **风险**：发现性严重依赖用户的探索欲（点击标题、点击歌词行、点击状态点），且多项高级操作的连续批处理效率不如方案 B 的侧边栏。
