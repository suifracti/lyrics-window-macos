# Lyric Island V3 与 V4 视觉诊断与微调优化报告

> **定位与原则**：
> - **V3 (Apple Music 沉浸主窗口)**：**零大改，保持原汁原味**。仅在原有成熟架构上做两项极小的微调优化（歌词区背景防透字暗幕 + 顶栏控制按钮胶囊化收纳），保留 100% 熟悉的 Apple Music 经典体感。
> - **V4 (Direction D 歌曲工作台)**：作为独立 `.experimental` 主窗口并存，提供“平时安静、需要时展开个人歌词工作台”的全新体验。
> - **零修改产品 Swift 代码**：本轮仅作为 UI 视觉顾问与 HTML 原型交付。

---

## 一、V3 优化原则：零大改，原基础上微调

V3 是广大用户最喜欢的 Apple Music 沉浸式主窗口（`mainWindow.appleMusicImmersiveV3.v3`），结构极其成熟，**绝对不需要做任何大改或重新设计**。

仅针对日常使用中的 2 个小痛点做**原基础上的原位微调**：

```
                    V3 原基础上的两项极小微调优化 (Minimal Refinements)

  ┌────────────────────────────────────────────────────────────────────────┐
  │ V3 现有经典 Apple Music 布局 (100% 保持不变)                           │
  │ · 45/55 大歌词分栏                                                     │
  │ · 全屏封面三色动态高斯模糊背景                                         │
  │ · 大字号粗体歌词平滑滚动                                               │
  │                                                                        │
  │ ➕ 微调 1: 智能防透字暗幕 (仅在背景与歌词画布间加一层 35% 渐变暗度)      │
  │ ➕ 微调 2: 顶栏胶囊收纳 (仅将右上角散落按钮收纳进 12px 磨砂小胶囊)       │
  └────────────────────────────────────────────────────────────────────────┘
```

1. **微调 1：歌词区防透字暗幕 (Backdrop Contrast Shield)**
   - **痛点**：遇高亮白底/高饱和专辑封面时，白字歌词局部对比度变弱。
   - **微调做法**：不改变背景颜色提取逻辑，仅在歌词画布下方叠加一层极其轻量的 `15% ~ 35%` 暗度 Fade 渐变遮罩，确保任何封面下白字歌词均清晰醒目。
2. **微调 2：顶栏控制按钮胶囊化对齐 (Quiet Tool Capsule)**
   - **痛点**：顶部右上角的搜索/设置/布局切换按钮独立散落，唤醒时略显硬。
   - **微调做法**：不改变按钮功能，仅用一个低调的 `12px` 圆角 macOS 磨砂小胶囊（`rgba(0,0,0,0.3)`）将它们包裹对齐，保持界面顶部极度干净。

## 二、V4 (Direction D) 视觉诊断

针对 V4 在 1200×760、520×720 及 Preview Matrix 真实截图的诊断：

1. **背景跳变与黑上加黑**：界面背景在 Hover、Inspector 展开或状态切换时偶发断层变纯黑（`#000000`），破坏了暗紫柔光氛围感。
2. **歌词横向挤压与强行截断**：Wide Inspector 展开时，主歌词区未采用弹性缩放，导致长歌词出现整句横向溢出。
3. **Small 模式粗暴压缩**：Small 视口（520px）未能重新组织紧凑层级，导致顶部播放器占用过多高度。
4. **无障碍 Focus Ring 常亮泄漏**：歌曲工作台按钮在正常鼠标启动下常亮明显的蓝色 Focus Ring。

## 四、总结

- **V3**：**零结构修改，零大改**。原汁原味保留现版 Apple Music 沉浸布局，仅做“防透字暗幕 + 顶栏胶囊”两项轻微提升。
- **V4**：全新 Direction D 歌曲工作台伴侣，平时安静，点击 `⌘I` 展开 Inspector。
- 两个版本作为独立 Stable ID 并存，切换方便，互不干扰。
