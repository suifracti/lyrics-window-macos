## 2. 歌曲工作台重新设计（用户任务语言）

### 2.1 严禁在默认工作台直接显示的工程术语
在普通用户可见的“歌曲工作台”第一层，**绝对禁止**直接平铺或暴露以下概念：
- `LRCLIB ID` / `QQ/Netease Track ID`
- `Claude 3.5` / `GPT-4o` / `OpenAI` 模型名称
- `MeCab` / `IPADIC` / `Ochasen` 形态分析器名称
- `Whisper` / `Speech Framework` / `DP` / `Dynamic Programming`
- `Level 3` / `Presentation Catalog` / `Stable ID`
- `confidence` 置信度数字（如 `0.9234`）
- `SQLite Migration Version` / `Database Schema`

### 2.2 替换为普通用户任务语言 (User-Facing Task Language)
工作台第一层全面洗牌，统一使用用户可理解的**功能与任务词汇**：

| 旧工程暴露词 | 新用户任务语言 | 所在区段 |
|-------------|---------------|---------|
| LRCLIB Candidate 489201 | 社区同步歌词 (已匹配) | 1. 歌词与版本 |
| AI Prompt Preset (Claude 3.5) | 智能意译 (自然流畅风格) | 2. 翻译与读音 |
| MeCab IPADIC Ruby pipeline | 汉字平假名注音 (已校准) | 2. 翻译与读音 |
| Whisper + DP Alignment | 逐行自动时间轴同步 | 3. 时间同步 |
| SQLite Version Table / Hash | 历史修改版本 (3) | 4. 事项与历史 |

### 2.3 工作台内部连续结构
工作台放弃“四张工程卡片堆叠的后台仪表盘”造型，重构为 macOS HIG 标准的 **原生 Inspector 连续分区**：

```
歌曲工作台 Inspector (380px)
├── 顶部：当前曲目摘要 (封面 + 曲名 + 艺人 + 播放状态)
├── 区段 1：歌词与版本 (当前采用版本 / 切换候选 / 重新搜索)
├── 区段 2：翻译与读音 (翻译风格 / 读音模式 / 行级注音校准)
├── 区段 3：时间同步 (时间轴对齐状态 / 自动同步 / 空格打轴接管)
├── 区段 4：事项与历史 (需注意处理事项 / 3 个历史版本时间轴)
├── 底部：导入与导出 ([导出 .lrc] [导入 TXT/LRC])
└── 展开项 (默认折叠)：高级详细信息与诊断 (来源 ID / API 耗时 / 模型参数)
```

## 3. 修正默认歌词层级硬约束

针对 Phase 3.0 审计指出的“多层歌词同时堆叠导致排版失控”问题，方向 D 确立了不可动摇的**默认显示硬约束**：

### 3.1 默认视图 (Original + 1 Auxiliary Layer)
* **当前高亮 Hero 行**：默认**只展示原文 + 翻译**（或在读音偏好模式下展示**原文 + Ruby**）。
* **绝对禁止**：在默认状态下同时显示 `Ruby + 原文 + 独立假名行 + 罗马音 + 翻译` 4 层堆叠。

```
【正确默认渲染】：
                   東京は夜七時 慌ただしい街に雨が降り出す        ← 原文 (Hero 26pt Bold)
                   东京晚上七点 匆忙的街头开始下起了雨            ← 翻译 (14pt Regular, 0.7 opacity)

【偏好读音模式渲染】：
                   とうきょう    よる しちじ  あわだ      まち   あめ   ふ  だ
                   東京    は  夜  七時  慌ただしい 街  に 雨 が 降 り出す ← Ruby + 原文
```

### 3.2 三层同时显示的受控场景
三层（Ruby + 原文 + 翻译）仅允许在以下 3 种显式场景下出现：
1. 用户在设置中主动勾选“学习模式（同时开启注音与译文）”；
2. 鼠标悬停在当前行并展开行级详细面板；
3. 用户长按当前歌词行。

### 3.3 非当前行的弱化策略
* **相邻行 (±1 行)**：保留原文 + 弱化译文（opacity 0.45，blur 0px）。
* **远端行 (±2 行及以上)**：**隐藏所有辅助层**（翻译/Ruby/罗马音完全不渲染），仅保留原文（opacity 0.25，blur 0.8px），最大程度集中视线。

## 4. 多表面统一语法 (Multi-Surface Family Rules)

方向 D 在所有 6 个表面保持可识别的产品家族基因，同时严守**“胶囊与桌面歌词为两个独立 WindowController”**的架构约束：

```
                              Lyric Island 多表面统一语法矩阵

  ┌───────────────────┐    ┌───────────────────┐    ┌───────────────────┐
  │ 1. 主窗口 Wide    │    │ 2. 主窗口 Small   │    │ 3. 歌词专注 Focus │
  │ · 1200 × 760      │    │ · 520 × 720       │    │ · 680 × 760       │
  │ · 45/55 分栏      │    │ · 顶部卡片+底部歌词│    │ · 纯歌词, 32pt 字 │
  │ · 380px Inspector │    │ · Bottom Sheet    │    │ · 微型播放浮条    │
  └───────────────────┘    └───────────────────┘    └───────────────────┘
  ┌───────────────────┐    ┌───────────────────┐    ┌───────────────────┐
  │ 4. 桌面歌词       │    │ 5. 顶部胶囊       │    │ 6. 16:10 全屏     │
  │ · 760 自由位置    │    │ · 240/280/420 3态 │    │ · 光源全屏扩散    │
  │ · 鼠标穿透 & 锁定 │    │ · 最多 1 行歌词   │    │ · 40pt 超级 Hero  │
  │ · 1-3 行透明玻璃  │    │ · 独立 WindowCtrl │    │ · ⌘I 呼出抽屉工作台│
  └───────────────────┘    └───────────────────┘    └───────────────────┘
```

### 统一共享的语法元素
1. **当前行 Hero 强调**：`scale(1.02)` 放大、100% 不透明度、主色发光衬底。
2. **字体与排版**：正文使用 SF Pro Display / Hiragino Sans，行距 `1.35`，字间距 `-0.3px`。
3. **封面光源背景**：通用 `BackdropPalette` 三色渐变提取 + 柔光暗幕 + 0.03 粒度程序化噪点。
4. **状态语言**：统一采用用户任务语言（"正在同步", "已校准", "未找到歌词"）。
5. **圆角与材质**：主窗口 `12px` / 桌面歌词 `16px` / 胶囊 `20–26px`，统一使用 macOS Vibrancy 毛玻璃。
